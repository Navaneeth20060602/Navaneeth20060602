### 🛡️ Fake Job Posting Detection

A Machine Learning + NLP powered Flask web app that detects fraudulent job postings. Uses semantic similarity to validate whether an input even resembles a real job posting before classifying it as **Legitimate**, **Fraudulent**, or **Invalid**.

**Tech Stack:**
`Python` `Flask` `Scikit-learn` `NLTK` `Sentence-Transformers` `Pandas`

**Highlights:**
- Compares Logistic Regression, Naive Bayes, Random Forest & Linear SVM — auto-selects the best model
- TF-IDF + semantic embedding based text preprocessing pipeline
- Clean Flask UI with real-time prediction

- End-to-end guided journey from idea to skill-building to mentorship
